# J.A.R.V.I.S. — Голосовой ИИ-ассистент

Умный голосовой ассистент с современным графическим интерфейсом на базе CustomTkinter. Проект распознает речь через локальную модель Whisper, генерирует контекстные ответы с помощью Google Gemini API и синтезирует естественную русскую речь через локальную модель Silero TTS v5.

##  Особенности
* **GUI:** Тёмная тема, статусы в реальном времени, вывод логов диалога.
* **Активация:** Поддержка активации по кодовому слову («Джарвис») или нажатие физической кнопки мыши (по умолчанию `x2`).
* **Адаптивный VAD (Voice Activity Detection):** Подавление эха — микрофон не слушает сам себя, когда Джарвис говорит через колонки.
* **Быстрый отклик:** Использование легковесных моделей (`faster-whisper` и `Gemini Flash`) для минимизации задержек.
* **Удобное управление:** Поддержка прерывания речи (barge-in) и режим аппаратной паузы.

##  Структура проекта
* `main.py` — Главный оркестратор и точка входа.
* `gui.py` — Графический интерфейс пользователя (CustomTkinter).
* `core/config.py` — Конфигурация и загрузка `.env`.
* `core/brain.py` — Модуль ИИ-логики и управления контекстом диалога (Google GenAI).
* `audio/recorder.py` — Модуль захвата звука и определения тишины.
* `audio/transcriber.py` — Модуль преобразования голоса в текст (Whisper).
* `tools/speaker.py` — Модуль синтеза речи и нормализации чисел (Silero TTS).

##  Требования к системе
* **ОС:** Windows 10/11 или Linux.
* **Python:** 3.10 – 3.12.
* **GPU (Рекомендуется):** Видеокарта NVIDIA с установленным CUDA Toolkit 12.x и cuDNN для мгновенной работы Whisper и Silero TTS.

## 🚀 Установка

1. Склонируйте репозиторий или распакуйте файлы проекта в удобную папку.
2. Рекомендуется создать виртуальное окружение:
   python -m venv .venv
   .venv\Scripts\activate

3. Установите зависимости:
   pip install -r requirements.txt
   
   *(Примечание для Windows: если при установке pyaudio возникает ошибка, установите его через колесо: pip install pipwin -> pipwin install pyaudio)*

## ⚙️ Настройка (.env)
Создайте файл `.env` в корневой директории проекта и добавьте в него ваш API-ключ Gemini, а также опциональные настройки:

api_key="ВАШ_КЛЮЧ_GEMINI"
HOTKEY="x2"                  # Кнопка мыши для активации
INPUT_DEVICE_INDEX="-1"      # Индекс микрофона (-1 для устройства по умолчанию)
SILENCE_THRESHOLD="450"      # Порог тишины (чувствительность микрофона)
SILENCE_DURATION="1.3"       # Секунд тишины для завершения фразы

## 🎙 Использование

Запустите проект из терминала:
python main.py

* **Активация голосом:** Скажите «Джарвис, [ваш вопрос]». Откроется сессия диалога на 10 секунд.
* **Активация кликом:** Нажмите горячую клавишу мыши (боковая кнопка `x2`) или синюю кнопку в интерфейсе. Джарвис сразу начнет вас слушать, называть имя не нужно.
* **Прерывание:** Если бот отвечает слишком долго, нажмите горячую клавишу мыши — Джарвис моментально замолчит.
* **Остановка/Сон:** Скажите «Стоп» (чтобы сбросить генерацию) или «Отбой / Завершение» (чтобы закрыть сессию).
